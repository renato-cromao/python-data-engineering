## Conceitos principais

### Variáveis

Variáveis são usadas para armazenar valores que podem ser reutilizados ao longo do código.

Exemplo:

```python
nome = "Renato"
idade = 42
altura = 1.81
```

### Tipos primitivos

Alguns dos principais tipos primitivos em Python são:

```python
texto = "Python"
numero_inteiro = 10
numero_decimal = 10.5
valor_logico = True
```

### Entrada e saída de dados

A função `print()` exibe informações na tela.

A função `input()` recebe informações digitadas pelo usuário.

```python
nome = input("Digite seu nome: ")
print("Olá,", nome)
```

### Operadores aritméticos

Python permite realizar operações matemáticas básicas:

```python
soma = 10 + 5
subtracao = 10 - 5
multiplicacao = 10 * 5
divisao = 10 / 5
```
