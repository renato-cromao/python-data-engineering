# 00 - Setup de Ambiente

Este módulo documenta a configuração inicial do ambiente utilizado na trilha de estudos em Python para Dados e Engenharia de Dados.

## Objetivo

Preparar um ambiente local organizado para estudar Python, praticar Git/GitHub e desenvolver projetos de dados de forma estruturada.

## Ferramentas utilizadas

- Python
- Git
- GitHub
- Git Bash
- Antigravity IDE
- Windows
